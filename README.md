# DailyFlow Task Manager

A lightweight, responsive task manager built with vanilla HTML, CSS, and JavaScript. No build tools or package installation required.

## Run it
1. Extract `DailyFlow-Task-Manager.zip`.
2. Open `index.html` in a modern browser.

Optional: serve the folder with a local web server for a more app-like development workflow.

## Features
- Create, edit, complete, and delete tasks
- Notes, due dates, and low/medium/high priorities
- Views for all tasks, today, upcoming, and completed
- Search and filter by priority
- Sort by recently added, due date, or priority
- Daily completion progress
- Light/dark theme toggle
- Responsive desktop and mobile layout
- Saves tasks and theme preference in browser `localStorage`

## Files
- `index.html` — app structure
- `styles.css` — layout, styling, and responsive rules
- `app.js` — task logic and local persistence

## Notes
Data is stored in the current browser on the current device. Clearing browser site data may remove saved tasks. This starter project does not include a server, user accounts, or cloud sync.
